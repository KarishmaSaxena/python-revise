# python-revise

A personal Python revision repository containing a series of Jupyter notebooks for practicing and reinforcing Python concepts through daily exercises.

## Overview

This repo includes notebook-based practice sessions from the first day through the tenth day, covering core Python fundamentals and problem-solving exercises.

## Notebook contents

- `1stday_practice.ipynb` — introductory Python practice
- `2ndday_.ipynb` — continued Python practice
- `3rdday_.ipynb` — more exercises and concepts
- `4thday.ipynb` — practice sessions
- `5thday.ipynb` — Python revision
- `6th.ipynb` — continued learning
- `7th.ipynb` — intermediate practice
- `8th.ipynb` — further Python exercises
- `9th.ipynb` — revision and implementation work
- `10th.ipynb` — final notebook in the series

## Purpose

This repository is intended for:

- revising Python basics
- practicing coding exercises
- learning through hands-on examples
- tracking progress across daily sessions

## Getting started

1. Install Python 3 on your system.
2. Install Jupyter Notebook or JupyterLab if needed.
3. Open the notebooks in Jupyter or VS Code.
4. Run the cells one by one to follow the exercises.

Example:

```bash
python --version
pip install notebook
jupyter notebook
```

## Recommended workflow

- Start with `1stday_practice.ipynb` and move forward in order.
- Practice each concept manually before moving to the next notebook.
- Revisit earlier notebooks whenever you need a quick refresher.
